# 音频素材规格（Audio Spec）

TeamSpeak 3 音效包对音频格式有软性要求。以下规格来自官方默认包与本项目实测校验：

| 项目 | 推荐值 | 说明 |
| --- | --- | --- |
| 容器格式 | WAV（RIFF/WAVE） | TS3 只识别 wav，不接受 mp3/ogg |
| 编码 | PCM（audioFormat = 1） | 校验脚本会拒绝非 PCM |
| 位深 | 16 bit | 16bit 是最常见兼容规格 |
| 采样率 | 44100 Hz | 44.1kHz 为推荐值，其他采样率可能被客户端重采样 |
| 声道 | 单声道（mono） | 官方包均为单声道；立体声也可用 |
| 时长 | 0.5 ~ 2 秒 | 提示音宜短促，过长会盖住对话 |

## 输出建议（以 Audacity 为例）

1. 录音 / 导入素材后：`轨道 → 重采样` 选 `44100`，`轨道 → 声道 → 单声道`
2. `文件 → 导出 → 导出为 WAV`，格式选 `PCM 16-bit`
3. 导出前用「效果 → 放大/标准化」把音量调到 -3 ~ -6 dB，避免爆音
4. 首尾各留 10~30ms 淡入淡出，避免“啪”的硬切声

## 校验工具对应项

`scripts/verify.ps1` 对每个被引用的 wav 检查：

- RIFF/WAVE 魔数
- audioFormat == 1（PCM）
- 采样率 44100（非 44100 仅警告）
- 位深 16（非 16 仅警告）
- 声道 ≤ 2（>2 仅警告）

格式异常会直接判定失败；规格偏差仅警告，不影响打包。
